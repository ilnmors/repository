## Notes

- Backend is [quartermaster](../quartermaster/README.md): `qwen3.8-flash-next` (chat, default), `bge-m3` (embeddings), `qwen-image-2.1` (images and image edits), and `wan2.2-enhanced-i2v` (video). `OPENAI_API_CONFIGS` lists only chat models in the model picker.
- API keys are enabled for service clients (Sure, OpenCode, Continue, etc.) with `ENABLE_API_KEYS_ENDPOINT_RESTRICTIONS=true`. Every key (including admin keys) is limited to `/api/chat/completions`, `/api/v1/chat/completions`, `/api/models`, `/api/embeddings`, and `/api/v1/videos/config/update` (admin-only, used by `video-connection.py`); chats, files, users, and settings stay out of reach.
- Reset on 2026-11-15: the database was dropped and recreated (with the `vector` extension), and the data directory and the `open-webui` bucket were emptied. Accounts are created again on the first Authelia login.
- Models cannot create or save skills and memories on their own: `DEFAULT_MODEL_METADATA` sets `builtinTools.user_input`, `builtinTools.skills`, and `builtinTools.memory` to `false`, and `ENABLE_MEMORY_BACKGROUND_REVIEW=false`. Skills and memories added by the user still apply (attached skills are inlined into the system prompt, memories into the system context). Model presets created later need the same `builtinTools` values.
- Tool defaults and context: `image_generation` and `video_generation` are on by default in every chat with `function_calling: native`. Web search ([searxng](../searxng/README.md), 5 results, `WEB_FETCH_MAX_CONTENT_LENGTH=20000`) and the code interpreter stay available on demand. Context compaction (`CONTEXT_COMPACTION_TOKEN_THRESHOLD=40000`) keeps long chats inside the 64k context; background LLM tasks (title, tags, follow-up, autocomplete) and community sharing are disabled.
- Images leave `IMAGE_SIZE` empty so each model's defaults in [quartermaster](../quartermaster/README.md) (1024×1024) apply, and `ENABLE_IMAGE_EDIT=true` points OpenAI image editing at `qwen-image-2.1` (`/v1/images/edits`). When `image_model` is `qwen-image-2.1`, `ansible/roles/containers/templates/openwebui/sync-functions.py` runs via `ExecStartPost` to keep the Global Filter `qwen_image_2_1_guide` (`ansible/roles/containers/templates/openwebui/qwen-image-filter.py`) active in PostgreSQL; it activates only when `features.image_generation` is enabled and avoids literal `N-head` proportion tokens, negative-style phrasing at CFG 1.0, non-32-multiple sizes, and redundant LoRA tags. Video connects to Quartermaster's `/v1/videos` adapter (port 8013) via `ansible/roles/containers/templates/openwebui/video-connection.py` on start (`VIDEO_GENERATION_TIMEOUT=10800`).
- Files are stored in RustFS (`open-webui` bucket); vectors in PostgreSQL (`pgvector`, max vector length 1024, token chunking 350/50).
- Library (2026-11-23): `/library/` is a files gallery (`ansible/roles/containers/templates/openwebui/library/index.html`, mounted read-only into `/app/build/library`), so Open WebUI serves it under its own login; without a valid token it sends the browser to `/auth?redirect=/library/`. It has a left sidebar (search, folders, type filter, summary) and opens on the folder overview, not on the files; clicking a file opens a viewer with its details and actions. Folders are the page's own: they live in the user's settings under the top-level key `library` (`{"folders": [...], "map": {"<file id>": "<folder id>"}}`), which Open WebUI does not read; new files are in "Unsorted". Renames and deletes go through Open WebUI's file API, so the database and the bucket stay in step. `loader.js` replaces the empty `/static/loader.js` hook (mounted over `/app/build/static/loader.js`, copied to the static folder at start) and adds a Library row below Workspace in the sidebar's user menu. The deploy stops when the image's `loader.js` is no longer the empty hook (`releases.yaml` `openwebui.patches`, `ansible/roles/containers/tasks/check-patches.yaml`); check that `/library/` still loads after an Open WebUI upgrade.

## Login

`ENABLE_LOGIN_FORM=false`, `ENABLE_PASSWORD_AUTH=false`, `ENABLE_SIGNUP=false`, `OAUTH_AUTO_REDIRECT=false` (Authelia OIDC).
