## Notes

- Replaced the separate llama.cpp and stable-diffusion.cpp servers on 2026-11-14. Open WebUI uses it for chat, embeddings and images.
- All four models (LFM2.5-24B-A2B, LFM2.5-VL-3B, LFM2.5-Embedding-350M, zImage-moodyRealMix) stay loaded together in one routing group and are preloaded at start.
- The image is rebuilt on Ubuntu 26.04 with the Mesa Vulkan drivers: upstream ships the Vulkan loader only, so the backends fell back to the CPU. The bundled sd-server (master-841) rendered noise on the Iris Xe; master-1098 renders correctly but needs glibc 2.43.
- 512×512 images render correctly. 1024×1024 renders noise on the Iris Xe, with or without diffusion flash attention (2026-11-15), so Open WebUI requests 512×512 (`IMAGE_SIZE`). 768×768 is untested. Recheck larger sizes on the RX 7900 XT.
- sd-server has no `/health`; its readiness check is `/v1/models`.
- The dashboard runs with `-admin-open`, so it has no public route.
- Unload a model with `POST /api/models/unload/<id>`.
- Qwen3.8-Flash-Next (`qwen3.8-flash-next`, ISTA GSQ-RCO IQ2_XS; a few Chinese words in Korean answers are accepted, IQ3_XXS was only slightly better and a third slower; the IQ3_XXS files are kept in DATA, its Strata pack and the Q2_0 files were removed on 2026-11-22) is served by Strata, bundled in the image from its release image (`releases.yaml`, `build.strata`): the engine needs only glibc from the system, so it runs beside the Vulkan backends. Quartermaster starts the image's entrypoint as the model command; the entrypoint is patched to serve on loopback without a key and to keep its state in `/data/strata`. The container gets `/dev/kfd`, unlimited memlock and a 2 GB `/dev/shm` for it.
- Strata on the RX 7900 XT (2026-11-20/21, 32k context, DFlash2, tuned preset, `pool-workers=10`, pinned resident experts, learned expert profile): decode IQ2_XS 44-59 t/s, IQ3_XXS 35-40, Q2_0 47-64. On the evaluation sample (GSM8K 60, HumanEval 40, KMMLU 90) IQ2_XS scored 83.2%, IQ3_XXS 83.7%, Q2_0 81.6% (weaker in Korean history).
- Han ban (2026-11-22): every request to `qwen3.8-flash-next` gets `logit_bias` -3 on the 55,659 tokens that contain a Han character or a UTF-8 lead byte E4-E9, set by quartermaster `filters.setParams` from `templates/quartermaster/han-token-ids.json` (a client's own `logit_bias` is replaced). On IQ2_XS, Korean answers with Han dropped from 9/30 to 0/30, prompts that ask for Han still get it (-5 starts to break that, -6 and -100 break it), speed unchanged, KMMLU unchanged on the items run. The list belongs to this tokenizer; rebuild it when the model changes.
- Image and video models (2026-11-22; Qwen Image 2.1 and MiniMax H3-Image removed from the config and from DATA): Moody Pro Mix Collector's Edition (Z-Image Turbo, default image model in Open WebUI), Moody Krea Mix V7 (Krea 2) and DaSiWa WAN 2.2 I2V v9 Lightspeed (image to video). Files that need a Civitai key are marked `manual: true` with their `file` name in `models.yaml`: download them by hand into DATA with the key (it is not stored) and check the SHA256 in the comment; the task stops if one is missing.
- Local quantization keeps the original in DATA and writes the GGUF next to it, with Quartermaster stopped (the conversion needs the RAM the chat model holds): `podman run --rm --entrypoint /opt/quartermaster/backends/bin/sd-server/<sd tag>-vulkan/sd-cli -v <DATA model dir>:/w <quartermaster image> -M convert -m /w/<original> -o /w/<name>-Q8_0.gguf --type q8_0`. Krea V7 bf16 26.3 GB became 13.6 GB (5 min), Moody Pro bf16 12.0 GB became 6.5 GB (2 min).
- Video: the image runs `templates/quartermaster/video/adapter.py` beside the server (`qm-entrypoint.sh`, port 8013 on the host). It offers the OpenAI video API Open WebUI uses (`POST /v1/videos`, `GET /v1/videos/{id}`, `GET /v1/videos/{id}/content`) on top of Quartermaster's `/sdcpp/v1/vid_gen` jobs, sizes a clip from the start image's shape when no size is given, and returns animated WebP, which loops like a GIF (`QM_VIDEO_OUTPUT_FORMAT`; WebM, AVI, or GIF converted with Pillow since sd-server has no GIF output, are the alternatives). Open WebUI has no environment variable for video connections, so `templates/openwebui/video-connection.py` registers it after each Open WebUI start with the console API key; `VIDEO_GENERATION_TIMEOUT` is three hours.
- Measured 2026-11-22 through Quartermaster (1024x1024, first request includes swapping the chat model out): Moody Pro Mix Q8_0 78 s first, 16 s warm, 9.0 GB VRAM peak (bf16: same picture at a fixed seed, 14.5 GB); Moody Krea Mix V7 Q8_0 48 s first, 26 s warm, 18.1 GB. Image to video through the adapter: a 3 s clip (49 frames, 16 fps) from a square Moody image rendered at 624x624 in 242 s with an 18.8 GB VRAM peak; the first frame matches the start image and the motion follows the prompt.
